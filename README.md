## ✨ Key Features
- **Role-Based Access Control (RBAC):** Distinct interfaces for Admins and Members.
- **Authentication & Authorization:** Secure user sign-up, login, and session management.
- **Gym Operations:** Class scheduling, item listings, and admin management tools.
- **Responsive Interface:** Rendered dynamically using EJS and clean layouts.

---

## 🛠️ Tech Stack
- **Back-End:** Node.js, Express.js
- **Front-End:** EJS, HTML5, CSS3, Bootstrap
- **Database:** MongoDB / Mongoose
